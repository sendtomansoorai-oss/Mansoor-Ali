# Mansoor Ali — Professional Portfolio

A responsive, dark navy and cyan portfolio website for Internal Audit, IT Audit and Cybersecurity, built with plain HTML and CSS for GitHub Pages.

## Before publishing
1. Open `index.html` in a text editor.
2. Replace the sample email address and LinkedIn link in the Contact section.
3. Verify all certification titles and update the case studies so they reflect only accurate, approved, anonymized work.
4. Do not upload confidential company information, internal audit reports, screenshots, customer information, or restricted evidence.

## Publish using GitHub Pages
1. Sign in to https://github.com/ or create an account.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload `index.html` to the repository root. You may also upload this `README.md`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then save.
6. Wait a few minutes, then visit `https://YOUR-USERNAME.github.io`.

Official guide: https://docs.github.com/en/pages/quickstart
